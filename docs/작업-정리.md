## 3. 현재 구현된 기능

### 과제 필수 요소
- 값, 단위, 출처, 출처 시각, 조회 시각, 기준 시간대(KST) 표시, 원자료(raw) 확인
- KST 날짜를 키로 일별 기록 (같은 날 여러 번 성공해도 1건)
- 실패 5종 합성 재생: 느린 응답, 401/403, 호출 제한, 오프라인, 응답 형식 변경 (각각 다른 `error_code`)
- 실패 후 마지막 정상값 보존 + "오래된 값" 표시 + 오류별 안내 + "다시 시도" 버튼
- 복구 asset `T04-RECOVER-D2` 재생 → `fresh`, `error_code: none`, 다음 날짜 기록 1건 추가
- SHA-256 해시 계산과 게시된 기준 해시와의 일치 확인
- 비밀값 0건: 키는 서버 환경변수에만 존재 (브라우저 코드, 응답, 헤더, 저장소에서 검색해 0건 확인)

### 데이터
- 1977-04-01부터 약 13,700건의 일별 기록을 한 번 가져와 브라우저에 저장, 이후 하루 한 번 최근 30일만 보충
- 자동 갱신: 열 때와 30분마다 (합성 실패 상태에서는 멈춤, 실제 실패는 자동 재시도)
- 표시 기간 선택: 1일, 7일, 30일, 90일, 180일, 365일, 10년, 전체(1977~)
- 기록 종류 구분: 실제 조회 / 소급 조회 / 수동 입력 / 합성(복구 asset)
- 내려받기: JSON, CSV (표 범위를 따름)
- 추가 통화 9종 중 최대 6개: 유로, 위안, 파운드, 호주 달러, 캐나다 달러, 스위스 프랑, 홍콩 달러, 싱가포르 달러, 태국 바트

### 화면
- 상태 표시: 정상일 때는 작은 한 줄 `● 최신값 (기준: 날짜 시각 KST)`, 실패일 때만 눈에 띄는 배너
- USD·JPY 카드 + 추가 통화 카드 (같은 격자), 전일 대비 칩(오르면 빨강 ▲, 내리면 파랑 ▼), 출처·시각이 들어간 한 줄 복사/공유
- 환율 계산기 (원·달러·엔·추가 통화 양방향, 100엔 표기 풀이)
- 차트: 단일 시리즈 SVG, 마우스 올리면 날짜·값·전일 대비, 그래프 드래그로 구간 선택, 점이 많으면 선으로 단순화
- 기간 통계(최고·최저·평균·변동폭·현재 위치), 교차 환율(달러/엔)과 원/엔 변화 원인 문장
- 일별 기록 표: 페이지 이동(25/50/100/200건), 표 범위(표시 기간/전체), 날짜로 이동, 행마다 ✨ AI 설명
- 다크 모드, 모바일 레이아웃, 오프라인 안내, 키보드 포커스 표시
- 오늘의 한 줄 요약 (수치와 문장을 모두 코드가 생성)

### AI 해설
- 글자가 나오는 대로 표시(스트리밍), 대화 기억(최근 3번), 새 대화 버튼
- 현재 값 + 보고 있는 기간(또는 드래그로 고른 구간)의 요약 통계를 함께 전달
- AI 도구: `get_exchange_rates`(원하는 기간의 환율 조회), `get_market_indicators`(코스피, 기준금리, 국고채 3년, 한·미 정책금리)
- 근거 공개: 답변 아래에 참고 데이터, 참고 지표, 조회 기간 표시. `📊 통계 근거` / `💭 일반 추론` 배지
- 모델 자동 전환(`gemini-flash-lite-latest` → `gemini-3.5-flash-lite` → `gemini-3.1-flash-lite`)
- 요청 제한(IP당 분당 20회, 하루 300회), 질문 200자 제한(서버에서 강제), 면책 문구 고정

## 5. 의도적으로 하지 않은 것과 이유

| 항목 | 이유 |
|---|---|
| 뉴스 기사 근거 답변 | 구글 뉴스 RSS는 피드 안에 "개인 피드 리더용, 그 밖의 사용 금지" 문구가 있음. 네이버 개발자센터는 검색 API 신규 발급이 막힌 것으로 보이고(제3자 문서 근거, 미확인) NAVER API HUB는 유료. GNews/NewsData 무료는 12시간 이상 지연. 구글 검색 연동은 무료 키로 429. GDELT는 불안정. **대신 한국은행 지표(코스피, 금리)를 근거로 사용** |
| 달러 15:30 종가 | 엔화 종가는 한국은행에 없고 "하나은행고시"만 있어서, 두 통화를 같은 기준으로 맞추려고 매매기준율 사용 |
| ECB(Frankfurter) | 한국 시장 값과 달라 비교가 왜곡되고, 오늘 조회값이 전날 값이었음 → 한국은행으로 전환 |
| AI가 한 줄 요약 작성 | 시간 기준을 섞고 표현이 과장됨 → 코드가 작성 |
| 기간 선택, 과거 시계열, 질문 200자 제한 등 이미 있던 항목 | 중복 구현 안 함 |

## 6. 확인하지 못한 것과 알려진 한계

- **실제 배포 환경(Vercel)에서의 동작**: 함수 제한 시간 30초 설정이 실제 배포에서 허용되는지, 응답 속도가 충분한지 확인하지 못함
- 한국은행의 **호출 제한 오류 코드**를 알지 못해 "초과/제한" 문구로 추정. 인증키 오류(`INFO-100`)와 데이터 없음(`INFO-200`)은 실제로 확인
- 요청 횟수 제한은 서버리스 인스턴스마다 메모리가 따로라 **최선의 방어**일 뿐 완벽하지 않음
- 모바일은 **390px 화면 에뮬레이션**으로만 확인, 실제 휴대폰은 미확인
- 마우스 호버 효과는 헤드리스 브라우저에서 **브라우저 엔진에 호버 상태를 강제로 적용**해서 확인
- 추가 통화 차트는 최대 5년까지
- 미국 정책금리는 월별이라 최신 값이 한 달가량 늦음
- 매매기준율은 영업일 하루 한 번 산출되어, 이른 시간에는 오늘 값이 없을 수 있음
- AI 규칙("원인으로 단정하지 말 것" 등)을 AI가 항상 지키는지는 몇 번의 시험으로만 확인
- 실제 AI 답변으로 긴 답변 화면을 다시 확인하지는 않음 (가짜 긴 답변으로 시험)
